# HR Analytics Dashboard | Excel

# Project Overview
This project focuses on analyzing Human Resources (HR) data using Microsoft Excel. The dashboard presents key workforce metrics and interactive visualizations to support data-driven HR decisions.

# Objectives
- Analyze employee distribution across departments and job roles.
- Track new hires and workforce composition.
- Understand employee demographics and age groups.
- Compare net salary across job roles.
- Evaluate employee performance and skill assessment scores.

# Tools & Skills
- Microsoft Excel
- Data Cleaning and Preparation
- Excel Formulas and KPI Calculations
- PivotTables and PivotCharts
- Slicers and Interactive Filters
- Data Visualization and Dashboard Design

# Key Performance Indicators (KPIs)
- Total Employees
- New Hires
- Average Tenure
- Average Performance
- Average Skill Assessment Score

# Dashboard Features
- Employee count by department
- Gender distribution
- Employee type analysis
- Top five job roles by employee count
- Employee count by age group
- Net salary by job role
- Performance category distribution
- Filters for gender, year, department, job role, and location

# Key Learnings
- Transforming raw HR data into meaningful insights.
- Building KPI cards and interactive dashboards.
- Using PivotTables, charts, and slicers for analysis.
- Presenting workforce information in a clear visual format.

# How to Use
1. Download the Excel workbook from this repository.
2. Open it in Microsoft Excel.
3. Use the available slicers and filters to explore the dashboard.
4. Review the KPIs and charts to analyze workforce trends.

# Note
The dashboard figures represent the data included in the workbook. Please verify the figures and calculations before drawing business conclusions. Use only anonymized or authorized data when sharing this project publicly.
